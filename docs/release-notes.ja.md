# MoMorph — リリースノート

MoMorph（Plugin・Web・MCP Server）の最新アップデート。

## 2026-07-09

**✨ 新機能・改善**

- **Item List のフィルタ（Plugin・Web）** — Screen Spec の Item List（Active タブ）に 4 列のフィルタを追加：`No`・`Name`（単一選択）、`UI Part`・`Spec Status`（複数選択、`Generating` / `AI completed` / `Gen error` / `In Progress` / `Done`）。列間・列内でフィルタが組み合わされ、`No` でソートしてもフィルタは維持、一致するアイテムがない場合は空状態を表示。フィルタ有効時はドラッグでの並べ替えを無効化。

**🐛 修正**

- **同期シートのプレビュー番号** — アイテムを再採番して MM → Google Sheet を再同期すると、プレビュー画像が新しい番号に更新されるように修正（従来は他の項目が正しくてもプレビュー画像だけ旧番号のまま残っていました）。
- **レイアウトのぼかし/透過（Plugin・Web）** — ぼかし効果（Layer Blur・Background Blur・グラスモーフィズム）が Figma デザイン通りに描画されるように修正（オーバーレイやパネルが不透明背景で表示される問題を解消）。
