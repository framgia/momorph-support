# MoMorph V2 — リリースノート

MoMorph V2（Web・Figmaプラグイン・MCP/API）のアップデートです。新しいリリースが上に表示されます。

## 2026-11-05 {#2026-11-05}

!!! warning "アップデート後のお願い"
    - 開いているWebページを再読み込みし、Figmaプラグインを開き直してください。
    - プラグインを接続するときは、プラグインに表示されたコードをブラウザに入力してください。Webに「Figmaプラグインを更新してください」と表示された場合は、プラグインを閉じて開き直してください。手順は[Figma Pluginにログイン](v2-user-guide.md#login-plugin)を参照してください。
    - 他の組織に属するプロジェクトは、manifestファイルでプラグインを入れ直してください。手順は[manifestファイルでプラグインをインストールする](v2-user-guide.md#install-manifest)を参照してください。

**🕘 バージョン履歴：UIを刷新**

- **履歴パネルの刷新（Web）** — 期間ごとにまとまり、ページ・編集者・編集の種類で絞り込めます。
- **バージョン名（Web）** — バージョンに名前を付けて、後から開けるようになりました。

**🔗 GitHub連携：コードの更新をノードのバッジで確認**

- **ノードのバッジ（Web）** — GitHubのファイルとリンクしたノードに、バッジを表示します。リンク後にファイルが更新されると、バッジで気付けます。
- **更新内容の確認（Web）** — バッジを開くと更新内容（コミット）を確認できます。確認後は、ノードの基準を最新バージョンに切り替えられます。

**🎨 キャンバス**

- **iframeノード（Web）** — Webページを埋め込むノードのサイズが大きくなり、中のページをズームできます。
- **付箋（Web）** — 付箋を置くとすぐ入力でき、「Note」の文字を消す必要がなくなりました。

**🧩 Figmaプラグイン**

- **プレビューSVG** — 最大100MBまでアップロードできます。変更のないSVGは再アップロードしないため、同期が速くなります。
- **Overviewタブ** — Webと同じ見た目になりました。

**🤖 MCPとAPI**

- **ロック中の要素** — ロック中のキャンバス要素は、`repin_source`、`set_source_version`、`ingest_image`、`ingest_figma`、`delete_page`でも変更や削除されません。
- **セクションの入れ子** — `parentId`で、セクションの中にセクションを何階層でも入れられます。

**🔧 その他の変更**

- 新規プロジェクトの作成が速くなりました。
- コメントのアイコンのドラッグ、コネクタのツールバー、フィルターのダイアログなど、キャンバスの細かな不具合を修正しました。
