## 2026-11-12 {#2026-11-12}

!!! warning "アップデート後のお願い"
    - 開いているWebページを再読み込みし、Figmaファイルを一度閉じて開き直してから、Figmaプラグインを起動してください。
    - 他の組織に属するプロジェクトは、manifestファイルでプラグインを入れ直してください。手順は[manifestファイルでプラグインをインストールする](v2-user-guide.md#install-manifest)を参照してください。
    - MCPをお使いの場合は、`@momorph/mcp`を7.0.0に更新してください。`ingest_figma`は、英数字・`_`・`-`のちょうど10文字の`figmaFrame.id`または`figmaFrame.figmaNodeId`（例：`login-page`）や`db:<数字>`の形式を受け付けなくなりました。別の長さのidに変更してください。この形式のidで取り込み済みのフレームは、`ingest_figma`で更新できなくなります。

**🔗 Figma連携：プロジェクト間のファイル移動に承認が必要に**

- **移動リクエストの送信（Web）** — 他のプロジェクトに連携済みのFigmaファイルを追加するときは、そのプロジェクトの管理者の承認が必要になりました。両方のプロジェクトの管理者であれば、承認なしでそのまま移動できます。リクエストには理由を添えられます。Figma一覧に「承認待ち」の行が表示され、必要ならリクエストを取り消せます。
- **承認・却下（Web）** — ファイルを持っているプロジェクトの管理者にベルで通知が届き、リクエストと理由を確認して承認または却下できます。結果は、リクエストを送った管理者にもベルで届きます。
- **ファイル数の上限** — 1プロジェクトにつきFigmaファイルは3つまでです。承認待ちのリクエストも、この数に含まれます。

**🕘 バージョン履歴**

- **行のまとめ（Web）** — 続けて繰り返した操作は×Nの1行にまとまります。2分以内に続いたAIの操作も1行にまとまります。
- **操作の種類を追加（Web）** — 貼り付け、グループ化、グループを解除、自動レイアウト（AIによる自動配置）が履歴に表示されます。まとめて移動する操作など、細かな操作は表示しません。
- AIエージェントの操作に、実行したユーザーの名前を表示します。Web埋め込みのフィルター名、名前変更ダイアログのプレースホルダー、絞り込み中の件数バッジも修正しました。

**🔗 GitHub連携**

- **閲覧者のバッジ表示（Web）** — GitHubバッジに、リポジトリ・ファイルパス・バージョンを表示しなくなりました。メンバーと管理者は、これまでどおり確認できます。

**📄 Specタブ**

- **画像の表示が速く（Web）** — 重いSVGの画面は、先にプレビュー画像を表示し、その後で完全なSVGに切り替えます。
- **スライドの上限（Web）** — スライド追加画面に1画面10枚までの注記を表示し、「+ 追加」の行に現在の枚数（n/10）を表示します。

**🧩 Figmaプラグイン**

- **フレーム画像の自動更新** — 同期のたび（画面を開く・Reload）に、キャンバス上のフレーム画像も最新のデザインに更新されます。
- Unsavedタブでクリックした行が、タブの読み込み完了後も選択されたままになりました。

**🤖 MCPとAPI**

- **`get_frame_image`** — 画面のスライドの画像リンク（PNGまたはSVG）を返します。
- **`upload_html_mock`** — HTMLファイルをキャンバスのモックノードとしてアップロードします。
- **`upsert_node`** — 内容に変更がないときは`unchanged`を返し、履歴にも記録しません。
- **`upload_screen_spec`** — 画面として保存されていないFigmaフレームを受け付けません。

**🔧 その他の変更**

- 文字を何度も編集したときの元に戻す・やり直しが、1ステップずつ動くようになりました。
- ノードは他のメンバーが編集している間だけロックされ、選択しているだけではロックされなくなりました。

## 2026-11-05 {#2026-11-05}

!!! warning "アップデート後のお願い"
    - 開いているWebページを再読み込みし、Figmaファイルを一度閉じて開き直してから、Figmaプラグインを起動してください。プラグインを開き直すだけでは反映されません。
    - プラグインを接続するときは、プラグインに表示されたコードをブラウザに入力してください。Webに「Figmaプラグインを更新してください」と表示された場合は、Figmaファイルを一度閉じて開き直してから、プラグインを起動してください。手順は[Figma Pluginにログイン](v2-user-guide.md#login-plugin)を参照してください。
    - 他の組織に属するプロジェクトは、manifestファイルでプラグインを入れ直してください。手順は[manifestファイルでプラグインをインストールする](v2-user-guide.md#install-manifest)を参照してください。

**🕘 バージョン履歴：UIを刷新**

- **履歴パネルの刷新（Web）** — 期間ごとにまとまり、ページ・編集者・編集の種類で絞り込めます。
- **バージョン名（Web）** — バージョンに名前を付けて、後から開けるようになりました。

**🔗 GitHub連携：コードの更新をノードのバッジで確認**

- **ノードのバッジ（Web）** — GitHubのファイルとリンクしたノードに、バッジを表示します。リンク後にファイルが更新されると、バッジで気付けます。
- **更新内容の確認（Web）** — バッジを開くと更新内容（コミット）を確認できます。確認後は、ノードの基準を最新バージョンに切り替えられます。

**🎨 キャンバス**

- **iframeノード（Web）** — Webページを埋め込むノードのサイズが大きくなり、中のページをズームできます。
- **付箋（Web）** — 付箋を置くとすぐ入力でき、「Note」の文字を消す必要がなくなりました。

**🧩 Figmaプラグイン**

- **プレビューSVG** — 最大100MBまでアップロードできます。変更のないSVGは再アップロードしないため、同期が速くなります。
- **Overviewタブ** — Webと同じ見た目になりました。

**🤖 MCPとAPI**

- **ロック中の要素** — ロック中のキャンバス要素は、`repin_source`、`set_source_version`、`ingest_image`、`ingest_figma`、`delete_page`でも変更や削除されません。
- **セクションの入れ子** — `parentId`で、セクションの中にセクションを何階層でも入れられます。

**🔧 その他の変更**

- 新規プロジェクトの作成が速くなりました。
- コメントのアイコンのドラッグ、コネクタのツールバー、フィルターのダイアログなど、キャンバスの細かな不具合を修正しました。
